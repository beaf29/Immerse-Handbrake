# Immerse-Handbrake
An immersive handbrake script for FiveM
I made Immerse Handbrake because I couldn’t find a FiveM script, free or paid, that felt and sounded like a real handbrake. I wanted something simple. You hear it click into place when you set it, it holds the vehicle, and you get a distinct release sound when you disengage it and drive away. I’m releasing it for free in my Discord, so feel free to come check it out and grab a copy. [Join the Immerse Solutions Discord](https://discord.gg/m7kfqmM6hh)
### Controls
Press `Space` once to engage the handbrake. Press `Space` again to release it. That’s the only control.

**Development notice:** I used AI tools to help develop this script.
